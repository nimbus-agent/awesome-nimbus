# Contributing to Awesome Nimbus

Thanks for helping grow the Nimbus ecosystem list.

## How to add an entry

1. Fork this repo and edit [`README.md`](./README.md).
2. Add your entry to the most appropriate section, in this format:

   ```markdown
   - [name](https://url) — One-line description, sentence case, ends with a period.
   ```

3. Keep entries **alphabetical** within their subsection (official entries excepted).
4. Open a pull request with a short note on what the entry is and why it belongs.

## Quality bar

- The project must be real, working, and related to Nimbus (a connector, recipe, extension, companion tool, guide, or integration).
- No paid placements, affiliate links, or self-promotion without substance.
- Prefer a public repository or published package over a marketing page.
- One entry per line; no duplicate entries across sections.

## Removals

If a listed project is abandoned, broken, or no longer relevant, open a PR removing it with a one-line rationale.
